# 📈 AI 量化选股系统 React 前端

本项目是基于 React + Vite 构建的 LangGraph 六节点多 Agent 协同选股前端可视化工作台。

## ✨ 核心特性

- **一键启动选股**：点击界面中心按钮即可调用后台启动 `agent/main.py` 执行多 Agent 量化研判全流程。
- **实时控制台流式展示**：通过 WebSocket 实现 `agent/main.py` 的 `stdout/stderr` 无缓冲逐行实时推流渲染。
- **六节点拓扑状态可视化**：实时监听运行进度，自动感知并点亮 Node 1~6 阶段（日线初筛 -> 过滤龙头 -> 16宫格生成 -> 技术面分析 -> 消息面分析 -> 终审投资决策）。
- **进程控制**：支持一键“终止”运行中的 Python 子进程树，避免后台孤儿进程。
- **控制台辅助功能**：支持日志即时关键字过滤、一键复制全部输出、导出 `.log` 文件、清屏以及终端全屏模式。
- **分时 16 宫格监控看板直通**：一旦检测到本地 16 宫格网页看板（如 `http://127.0.0.1:8888`），界面自动浮现大屏快捷访问卡片。

## 🚀 快速启动

### 1. 启动后端 API 服务 (工作区根目录下)
```bash
python server.py
```
> 后端服务运行于 `http://127.0.0.1:8000`，提供 WebSocket 流式终端接口及控制接口。

### 2. 启动前端页面 (frontend 目录下)
```bash
npm run dev
```
> 前端开发服务器启动于 `http://localhost:5173/`。

### 3. 一键启动脚本
在项目根目录运行 [`run/windows/start.bat`](../run/windows/start.bat)（或 Linux 执行 `bash run/linux/start.sh`）即可同时启动后端与前端。
